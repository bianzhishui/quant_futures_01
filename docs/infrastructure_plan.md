## 1. 背景与目标

本仓库为期货量化研究项目（quant_futures_01）。经用户确认：

- **方向**：先搭研究基础设施，暂不定策略；
- **品种范围**：全品种商品期货（多板块分散）；
- **目标**：纯研究探索（回测验证），非实盘。

本次构建的是**任何策略研究的前提**：可信的数据管道、保守的成本模型、可验证的回测框架、以及一个中性的对照基准。本阶段不产生"策略 alpha"，基准/框架的数字**不代表策略收益**。

## 2. 假设（定死）

1. 日线级别研究（非日内），信号频率 ≤ 日频；
2. 数据源用免费可复现的 **akshare**（主力连续合约日线）；接口可能变化，本方案以数据校验门禁兜底；
3. 交易执行按"**收盘信号 → 次日开盘成交**"，避免前视；
4. 组合层先采用**多品种等权 + 波动率目标（年化 15%）**，作为后续一切策略的默认仓位框架；
5. 品种池、成本参数、回测参数均为**冻结参数**（config.py FROZEN_PARAMS 校验），改动须另写预注册。

## 3. 规则（定死）

### 3.1 品种池（冻结，起始 ~30 个流动性品种，5 板块）

| 板块 | 品种（交易所） |
|---|---|
| 黑色 | 螺纹钢 rb(上期) 热卷 hc(上期) 铁矿石 i(大商) 焦炭 j(大商) 焦煤 jm(大商) |
| 有色 | 沪铜 cu 沪铝 al 沪锌 zn 沪镍 ni 沪锡 sn 不锈钢 ss(上期) |
| 贵金属 | 沪金 au 沪银 ag(上期) |
| 能化 | 原油 sc(能源) 燃料油 fu 沥青 bu(上期) PTA TA 甲醇 MA(郑商) 塑料 L 聚丙烯 PP 乙二醇 EG(大商) 橡胶 ru(上期) |
| 农产品 | 豆粕 m 豆油 y 棕榈油 p 玉米 c(大商) 菜油 OI 菜粕 RM 棉花 CF 白糖 SR(郑商) |

- 具体品种与 akshare 主力连续代码的映射在实施 M1 校验，映射表入 `config/default.yaml`（冻结）；
- 之后增减品种须预注册。

### 3.2 数据规则（定死）

1. **周期**：日线；**覆盖**：统一从 **2018-01-01** 起（保证样本数充足且品种池稳定）；各品种更早历史保留但回测不纳入；
2. **存储**：`data/futures_main_daily/` 下按品种 parquet（gitignore，不入库）；
3. **清洗**：删除停牌/无交易行；价格/成交量 NaN → 报错不静默填充（权威数据缺失要暴露）；
4. **展期**：使用 akshare 主力连续（含换月价差）；**拼接后做后复权处理**消除换月跳空，复权因子随数据落盘（`data/futures_main_daily/{symbol}_adj.parquet`）；
5. **不变量**：复权前后价格序列逐日可互相推导（对拍验证）；无未来数据混入（按日索引严格递增）。

### 3.3 成本模型（定死，冻结）

1. **手续费**：按交易所公开标准 × **2（保守系数）**；每手费额/比例按品种配置（`config/cost.yaml` 或 default.yaml costs 段）；拿不到精确标准的品种用同板块近似并标注；
2. **滑点**：统一 **0.05% 单边**（保守，覆盖多数流动品种）；后续可预注册改为按品种 tick 细化；
3. **保证金率**：统一 **10%**（用于仓位/杠杆计算，非实盘精确值）；
4. 以上全部入 config 并标注冻结；成本对结论敏感处，报告需给成本区间敏感性（±50%）。

### 3.4 回测约定（定死）

1. 信号在 **T 日收盘**生成，**T+1 开盘价**成交（含滑点与手续费）；
2. 仓位：**波动率目标**——组合目标年化波动 **15%**，品种等权权重 × 各自波动率倒数（滚动 60 日年化波动，下限截断防爆仓）；
3. **每日再平衡**；单品种名义仓位上限（如 ≤ 组合权益 200%，防集中）；
4. 指标：年化收益、年化波动、夏普、最大回撤、卡玛、月胜率、换手率、**成本拖累**（毛 vs 净）、分板块/分品种贡献；
5. **不变量校验**（每次跑完回测抽查）：① 期末权益 = 现金 + 持仓市值；② 周期收益连乘 = 累计净值；③ 无负保证金穿透。

### 3.5 基准（定死）

1. **基准 A：等权买入持有**——所有品种等权多头、每日再平衡、同样成本模型（对照"不做信号"的收益）；
2. **基准 B：简单趋势**（20 日均线多空，全品种等权）——仅作框架冒烟/自检用，**不视为策略结论**；
3. 所有策略/基准统一在 2018-01-01 至最新可得数据区间跑，区间一致才可比。

## 5. 诚实风险

1. **数据源风险**：akshare 接口/字段/主力连续定义可能变动或与交易所官方有出入——以校验门禁 G1/G2 兜底，发现偏差按实际修正并在 §0 记录；
2. **展期处理敏感**：换月价差处理方式不同，回测结果可能明显不同——本方案固定一种（后复权）并落盘因子，后续对比需另预注册；
3. **成本假设不精确**：统一滑点/保证金为保守估计，非实盘精确值；对成本敏感的结论需附敏感性；
4. **框架 bug 风险**：回测引擎实现错误会污染一切后续结论——用 G3 对拍 + G4 不变量 + G5 测试缓解；
5. **样本偏差**：2018 年前上市品种才全程纳入，新品种（如工业硅、碳酸锂）不在起始池，避免幸存者偏差；
6. **基准 ≠ 策略**：本阶段数字只是基线，不能解读为任何策略的表现。
