## 1. 背景与目标

动量家族三连败后，需回答："是动量无效，还是这个市场（中国商品 2018-2026）难做？" 期限结构/carry 是**独立的第二溢价来源**（风险补偿：持有近月承担展期，backwardation 时多头吃正 carry），且动量家族的共同失败点（空头腿）在 carry 上性质不同（做空 contango 品种 ≠ 做空近期输家）。

**目标**：
- 阶段一：建立**近远月期限结构数据管道**（主力-次主力斜率因子）；
- 阶段二：验证 carry 信号（净成本后）是否优于基准 A，且多空两腿有效。

## 2. 数据可行性结论（2026-09-20 实测，方案据此定稿）

| 数据源 | 结论 |
|---|---|
| `ak.get_futures_daily`（交易所官方逐合约） | **SHFE / CZCE / INE 全年范围可用**（SHFE 2018 全年 67s / CZCE 87s / INE 45s；9 年 ≈ 30 分钟后台）✅ |
| 同上（DCE 大商所） | **全部失效**（JSONDecodeError，`get_dce_daily` 亦失败且仅支持按日）❌ |
| sina 逐合约（`futures_zh_daily_sina`） | 不覆盖 2018 老合约（I1801/SR1801/CU1801/M1801 全失败）❌ |

→ **阶段一品种范围 = SHFE/CZCE/INE 的 20 个品种**（DCE 10 品种因数据源失效一期排除，作为范围局限如实记录；待 akshare 修复或换源后预注册补充）。

## 3. 假设（定死）

1. **期限结构斜率（carry）是系统性风险溢价**：backwardation（近月>远月）品种多头、contango（近月<远月）品种空头，净成本后为正；
2. 该效应在中国商品 2018-2026（20 品种子集）上成立；
3. 价值来自 carry 本身（非动量、非市场 beta）。

## 4. 规则（定死，不可事后调参）

### 4.1 阶段一 · 数据管道（冻结）
- 数据源：`get_futures_daily` 按（交易所 × 年）拉取 SHFE/CZCE/INE，2018-01-01 起；
- 每品种每日：当日交易的合约按 **open_interest（持仓量）排序** → `F1` = 最大（主力）、`F2` = 次大（次主力）；
- **斜率因子** `slope[t] = F1.close[t] / F2.close[t] − 1`（原始价，同日两合约价差，无需复权）；
- 落盘 `data/term_structure/{SYMBOL}.parquet`（date, F1, F2, slope, oi1, oi2），gitignore；
- **校验门禁**：① 每品种行数/区间可查；② 抽查 F1 价格与主力连续对拍（同源同日应一致或可解释）；③ 无 NaN 斜率。

### 4.2 阶段二 · carry 信号（冻结）
- 信号在 **T-1 收盘**决定（无前视）：`sig_i[t] = +1`（slope > 0，backwardation，做多）／`−1`（slope < 0，contango，做空）／`0`（slope = 0 或数据缺失）；
- **权重**：等权幅度 `1/N`（N = 当日有斜率数据的可交易品种数），`w_i[t] = sig_i[t]/N`；
- 每日再平衡；成本模型沿用 infra（0.02% + 0.05% 单边，冻结）；
- **执行近似（诚实标注）**：回测持有**主力连续（后复权）**——与动量家族同口径可比，但**展期收益已被复权剔除，carry 捕获不完整**；真正的逐合约展期模拟为后续增强（另立预注册）。

### 4.3 灵敏度/定义稳健性（诊断，仅报告）
- 主力定义：OI 排序 vs 成交量排序；
- 远月选择：次主力 vs 第 3 远月；
- 信号形态：符号 vs 幅度加权（|slope| 归一化）。

### 4.4 对照基准
- 基准 A（等权多头，20 品种子集同口径）；基准 V 背景。

## 6. 诚实风险

1. **DCE 10 品种一期排除**（数据源失效）：结论只对 20 品种子集成立，不可外推全品种；黑色（4/5）与豆粕/豆油缺席，可能高估或低估 carry 效果；
2. **执行近似**：主力连续回测不完整捕获展期收益——若信号方向正确，真实 carry 捕获可能比回测更好或更差（取决于展期实施）；§0 必须如实标注；
3. **第四方案的多重检验**：与前三个方案同一 2018-2026 样本，但**跨溢价来源**（非动量家族）；仍未做家族级校正，§0 标注；
4. **近月合约流动性**：次主力合约流动性可能不足（执行风险未建模）；持仓量排名本身含噪声；
5. 其余同前：做空约束未建模、成本保守近似、主力连续小跳变。
