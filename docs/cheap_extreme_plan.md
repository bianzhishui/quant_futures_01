## 1. 背景与目标

傅海棠框架三条铁则中，"成本铁底/供给收缩"依赖低频行业数据（免费不可得），唯"**情绪冰点 + 价格极低**"可用价格数据做代理。阶段一做两件事：

1. **当前市场扫描**：用现价历史分位 + 深跌程度 + 波动/期限结构位置，输出"贱极候选池"（供人工用行业数据确认成本/供给，这是框架的合理分工——机器筛、人确认）；
2. **历史验证**：检验假设"价格处历史低分位 + 深跌（贱极代理）后 6/12 个月，多头持有是否跑赢等权基准（净成本后）"——**把傅海棠的"贱极则贵"转成可检验的统计假设**。

## 2. 假设（定死）

1. "贱极则贵"在统计上有边际：**价格近 5 年分位 ≤ 10% 且距 250 日高点回撤 ≥ 30%**（入池事件）后 6/12 个月，多头持有净收益/夏普**跑赢同窗口等权基准**；
2. 呼应窗口发现：该边际在**危机 regime（2010-2017）比金属牛（2018-2026）更强**（傅海棠方法本质是危机 contrarian）。

## 3. 规则（定死，不可事后调参）

### 3.1 入池事件（冻结）
- 用**后复权 adj_close**（避免换月跳变污染）：
  - **D1 价格分位**：现价在**近 5 年（1260 交易日，min_periods=500）**滚动窗口的分位；**≤ 10% = 贱极**（≤ 5% 标注"极贱"）；
  - **D2 深跌**：距 **250 日滚动高点**回撤 **≥ 30%**；
  - 入池硬门槛：**D1 ≤ 10% 且 D2 ≥ 30%**（冻结）。
- **标注维度（不入池门槛）**：D3 60 日年化波动历史分位（情绪）；D4 期限结构斜率分位（20 品种，contango 深 = 悲观标注）；D5 品种板块。

### 3.2 事件回测（冻结）
- 事件日 = 当日入池（D1+D2 同时满足）；**重叠处理**：同一品种连续入池只计首个事件日（事件间隔 ≥ 60 日去重）；
- 持有：事件日后**持有 6 个月 / 12 个月**（等权多头，持有至期末，中途不退）；
- 成本：入场/出场各付单边成本（沿用 infra 0.05%+0.02%）；
- 对照：同窗口同品种池的**等权基准 A**（同期累计收益/年化）；
- 统计：事件数、平均持有收益、超额（vs 基准）、事件年化夏普、分板块事件分布。

### 3.3 当前市场快照
- 截至最新交易日（2026-09-21）各品种的 D1-D5 表 + 入池候选列表（若有）。

## 4. 判定标准（写死）

| # | 门禁 | 判定 |
|---|---|---|
| G1 | 工程 | 扫描器/事件回测可复现（两次运行一致）；pytest 全过；ruff 0 |
| G2 | 有效性 | 事件 6 个月平均超额（vs 同期基准）> 0，且事件 12 个月平均超额 > 0 |
| G3 | 子时段一致 | 2010-2017 与 2018-2026 两段事件超额**同号**（预期都为正、或危机段更强但不得反转） |
| G4 | 板块分散 | 单板块事件占比 ≤ 60%（防"贱极=某板块崩盘"单一解释） |

**结论规则**：G1∧G2∧G3∧G4 → ✅ "贱极代理有统计边际"，可作为**筛选器**纳入工具（供人工确认）；G2/G3 部分未过 → 🟡 标注（如仅危机段有效 → 结论为"regime 依赖的筛选器"）；均未过 → ❌ "价格极低分位代理无边际"，阶段一止步于工具（仍有扫描价值）。

## 5. 诚实风险

1. **代理 ≠ 真实铁则**：价格低分位 ≠ 跌破全行业成本；情绪冰点无直接度量——本验证只检验"价格代理"是否有边际，**不验证傅海棠完整方法**；
2. **事件重叠与幸存者偏差**：深跌事件常连续（去重缓解）；品种 2010 后陆续上市（窗口内可比处理）；
3. **同一 2010-2026 样本**（已含金属牛段），多重检验未校正；结论是"筛选器有效性"，非策略；
4. **不可重仓**：即使统计有边际，"贱极"也可能长期阴跌（价值陷阱）——本工具只输出候选，仓位/重仓决策须人工+行业数据确认。
