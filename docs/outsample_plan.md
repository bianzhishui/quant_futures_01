| 指标 | W1 (2010-2017) | W2 (2018-2026) |
|---|---|---|
| TSMOM 夏普 | **+0.074** | −0.473 |

| TSMOM 空头腿 | **+0.110（正！）** | −0.401 |
| 长多腿赢家板块 | 农产品 50% / 黑色 35% / 有色 22%（分散） | 有色 50% / 贵金属 40%（金属） |
| 协方差风控实现波动 | **9.5%**（未达 15% 目标） | 15.3% ✓ |

**核心结论修正（写死）**：
1. **"简单信号/空头在中国商品无效"是 2018-2026 窗口特定的，不普适**：W1 中 TSMOM 显著跑赢深亏的等权基准（+0.07 vs −0.25），**空头腿 +0.11 正贡献**——旧 regime 中趋势/做空在 2015-16 商品危机中有效；
2. **"金属 beta"同样是窗口特定**：W1 动量赢家是农产品+黑色（分散），金属仅 22%——金属集中是 2018-26 独有；
3. **风控框架精度 regime 依赖**：协方差波动率目标在 W1 实现波动仅 9.5%（未达 15%），W2 15.3%——框架的"贴近目标"能力随 regime 变化；
4. **对研究的含义**：2018-2026 是"金属单边牛市"窗口，简单多头信号必然显得有效（beta 幻觉），而**趋势/空头在被危机主导的 2010-2017 有真实价值**——**窗口结构比策略设计更决定结果**；该样本上两窗口结论不能互相外推。

## 1. 背景与目标

回答一个科学问题：**"中国商品期货简单信号无效、空头无贡献"是结构性的，还是 2018-2026 金属牛市特有的？**

- 2010-2017 regime 与 2018-2026 结构迥异（2015-16 商品危机、2016 供给侧暴涨、黄金 2011 见顶后长熊、黑色系主导、无持续金属牛市）；
- 若旧窗口**同样失败** → 结论**结构性**，研究可真正收官；
- 若旧窗口**信号/空头有效** → 结论**窗口特定**，须修正（本身就是重大发现）。

## 2. 数据可行性（2026-09-21 实测）

sina 主力连续早段历史完整可得：RB0 自 **2009-03**、CU0/M0 自 **2005-01**、AU0 自 **2008-01**、I0 自 **2013-10**、TA0 自 **2006-12** → **2010-01-01 ~ 2017-12-31 窗口可行**；窗口内晚上市品种（I0 等）按可交易归一化处理（沿用 infra）。

## 3. 规则（定死，不可事后调参）

### 3.1 数据与窗口（冻结）
- 重拉主力连续日线**全历史**（不再从 2018 截断）→ 清洗/后复权落盘（覆盖 data/futures_main_daily/）；
- **对拍**：2018-2026 段收益与旧版（2018 锚定）逐日一致（后复权锚点变化只影响水平、不影响收益——须验证）；
- 复验窗口 **W1 = 2010-01-01 ~ 2017-12-31**；对照 **W2 = 2018-01-01 ~ 2026-09-21**（沿用现有结论）；
- 正式扩窗：`backtest.start_date` 从 2018-01-01 改为 **2010-01-01**（冻结参数变更，本方案批准即生效；§0 历史记录不受影响）。

### 3.2 复验内容（冻结）
| 项 | 内容 |
|---|---|
| R1 基准与动量 | 等权基准 A、TSMOM（L=120 等权）在 W1 vs W2：信号是否同样无边际（TSMOM 夏普 ≤ 基准 A）？ |
| R2 空头腿 | TSMOM 多空腿分解在 W1：空头腿是否同样无正贡献？（2018-26 空头全败） |
| R3 板块结构 | W1 动量长多腿的板块分解：正贡献是否仍集中于单一板块（W2 是金属）？——若 W1 赢家是黑色/其他，说明"金属 beta"是窗口特定 |
| R4 风控框架 | 协方差波动率目标（V2）在 W1 的实现波动是否仍贴近 15% 目标（风控框架普适性） |

### 3.3 成本与执行
- 沿用 infra：成本模型、每日再平衡、T-1 决定 T 生效、不变量检查——**两窗口完全同口径**。

## 4. 判定标准（写死）

| G1 | 数据管道 | 早段数据落盘、2018-26 段收益与旧版对拍一致（max err < 1e-9）、W1 品种/行数可查 |
| G2 | 复验完整 | R1–R4 全部产出（含多空腿/板块分解/风控框架指标） |

**结论规则（写死，窗口不可事后换）**：
- **若 W1 与 W2 结论一致**（R1 信号无边际、R2 空头无贡献）→ ✅ **结论结构性**："中国商品 2010-2026 简单信号/空头无普适 edge"；研究收官（可归档、写终稿）；
- **若 W1 信号/空头有效**（R1 或 R2 反例）→ 🟡 **结论窗口特定**：修正 RESEARCH.md/AGENTS.md 表述（"2018-26 金属牛市特有"），并指出旧 regime 的可探索方向；
- R3 板块结构变化不单独定结论，仅作解读支撑。

## 5. 诚实风险

1. **旧窗口数据质量**：2010-2014 主连换月处理/数据完整性与近年不同——以 G1 对拍 + 行数检查兜底，发现偏差如实记录；
2. **品种池随时间变化**：W1 品种数（约 25-28 个，I0 等晚上市部分期）与 W2（30 个）不同——比较以"同窗口内策略 vs 基准"的相对关系为主，跨窗口绝对值不作严格比较；
3. **这不是"选个好窗口"**：预注册判定写死，实施后不可因结果不如意改窗口；
4. **前视警示**：扩窗后的复权仍锚定最新价（后复权），但收益序列局部（无未来依赖，已在 measurement_plan 验证）——窗口切换不引入前视。
