## 1. 背景与目标

上一轮等权 TSMOM 失败的关键归因之一：**等权幅度被高波动品种主导**（黑色/能化贡献 96%），且组合未做风险均衡。本轮验证：

**在同样的 30 品种、同样区间、同样 L=120 方向信号下，把幅度换成波动率目标框架后，方向信号是否在"波动率目标长多占位"之上产生增量价值（净成本后）。**

## 2. 假设（定死）

1. 上一轮失败主要源于**幅度/风险配置**而非方向信号本身；
2. 波动率目标化（等权×波动率倒数）后，方向信号对组合有**增量**（净夏普提升）；
3. 增量必须来自多空两腿（或至少非仅空头腿），非单纯杠杆/做空。

## 3. 规则（定死，不可事后调参）

### 3.1 信号（与上轮完全一致，冻结）
- L = **120 交易日**；`sig_i[t] = sign(adj_close_i[t-1]/adj_close_i[t-1-L] − 1)`，T-1 决定、T 生效，无前视。

### 3.2 幅度与权重（本轮改动，冻结）
- 幅度 `m_i[t]` = 波动率目标框架（`vol_target_weights`：等权 × 波动率倒数，滚动 60 日年化波动下限 0.05，目标组合年化波动 15%，单品种名义上限 2.0；沿用 infra 冻结参数）；
- `w_i[t] = sig_i[t] × m_i[t]`（多空混合，名义由框架决定 ≈ Σ|m| ≈ 0.8–1.3）；
- 每日再平衡；成本模型沿用 infra（0.02% + 0.05% 单边，冻结）。

### 3.3 对照基准（本轮更换，冻结）
- **基准 V：波动率目标长多占位**（`--weights vol`，即 sig 恒 +1 的同一框架）——增量门禁的"并入前"状态；
- 基准 A（等权多头）仅作背景参照。

### 3.4 灵敏度与分解（诊断，仅报告）
- L ∈ {20, 60, 120, 250} 净夏普表（高原判据）；
- **多空分解**：长多腿/空头腿各自累计贡献（诊断空头腿是否为唯一来源）。

## 4. 判定标准（写死）

| # | 门禁 | 判定 |
|---|---|---|
| G1 | 工程 | pytest 全过 + ruff 0 + import 过 + 两次运行一致 |
| G2 | **增量门禁** | 净夏普(vol-TSMOM, L=120) > 净夏普(基准 V vol 长多) |

## 5. 诚实风险

1. 与前轮相同：**"报告期"非真样本外**（子时段一致性近似），§0 必须如实标注；
2. 波动率目标框架自身实现波动 ≈8.5% 低于目标 15%（infra 已记录）——两腿同框架，比较公平但绝对值可能偏低；
3. 若本轮通过，仍需警惕"同一数据上第二发子弹"（两轮都在同一 2018-2026 样本上检验）——统计多重检验风险，§0 如实说明；
4. 做空约束未建模（与前轮相同）；主力连续小跳变未完全消除（同前）。
