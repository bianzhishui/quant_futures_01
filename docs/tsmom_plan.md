## 1. 背景与目标

基于"期货交易本质"判断（零和 + 杠杆 + 结构风险溢价），第一类可统计提取的溢价是**惯性/动量**（价格对信息反应不足 → 短期趋势延续）。本方案验证：

**在 30 品种商品期货上（2018-2026），简单时序动量方向信号（净成本后）是否显著优于等权买入持有基准，且具备稳健性。**

选型理由（写死）：
1. 仅用现有主力连续日线即可实现，不依赖额外数据；
2. 与基准 A（等权多头）**同口径可比**——同样的等权幅度、同样的成本模型，唯一差异 = 方向信号 + 允许做空，从而干净地隔离"信号边际"；
3. 是 CTA 经典起点（Moskowitz-Ooi-Pedersen 2012 TSMOM 文献背景）。

## 2. 假设（定死）

1. **价格对信息反应不足**：过去一段时间的收益方向在短期内有延续性（趋势惯性）；
2. 该效应在中国商品期货 2018-2026 上**净成本后**仍为正；
3. 价值来自**方向信号本身**（含做空腿），而非单纯靠做空/加杠杆——故与基准 A 唯一差异是方向。

## 3. 规则（定死，不可事后调参）

### 3.1 信号（主规则，冻结）

- 回看窗口 **L = 120 交易日**（≈6 个月；TSMOM 文献报告的有效段之一，**非本样本选取**）；
- 信号在 **T-1 收盘**决定（无前视）：
  - `rL_i[t] = adj_close_i[t-1] / adj_close_i[t-1-L] − 1`
  - `sig_i[t] = +1`（rL > 0）／`−1`（rL < 0）／`0`（rL = 0）
- T 日生效，close-to-close 收益近似开盘成交（沿用 infra）。

### 3.2 权重（主规则，冻结）

- 等权幅度 `1/N`，N = 当日可交易品种数（复用 infra 的 tradable 归一化，上市前权重 0）；
- `w_i[t] = sig_i[t] / N`（总名义 = 1，多空混合）；
- 每日再平衡；成本模型沿用 infra（手续费 0.02% + 滑点 0.05% 单边，冻结）。

### 3.3 灵敏度扫描（诊断，仅报告，**不用于选参、不改变判定**）

- L ∈ {20, 60, 120, 250} 的全样本净夏普表；
- 用途：按"高原判据"（skill §1.3）检查 120 是否为孤立尖峰。

### 3.4 对比基准

- 基准 A（等权买入持有，infra 已实现）；同区间 2018-01-02 ~ 2026-09-18。

## 5. 诚实风险（如实呈现）

1. **"报告期"而非真样本外**：整个 2018-2026 既观察又验证，首次策略无法真正样本外——以 G3a 子时段一致性近似，§0 必须如实标注"未经未来样本外验证"；
2. **趋势策略周期性回撤**：震荡市连续磨损；区间含 2020 疫情、2021 商品牛市、2022 地缘冲突等结构性行情，结果可能依赖少数事件；
3. **零和与拥挤**：TSMOM 广为人知、CTA 拥挤度上升、程序化监管趋严——历史有效 ≠ 未来有效；
4. **做空约束未建模**：中国商品期货部分品种做空成本/保证金差异未计入，可能高估做空腿收益；
5. **数据局限**：主力连续小换月跳变未完全消除（infra 已记录）；成本为保守统一近似；
6. **不承诺实盘**：通过仅意味着"可并入组合的信号候选"，非实盘信号。
