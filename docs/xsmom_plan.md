## 1. 背景与目标

前两轮否决不能区分两种解释：**A) 动量溢价在中国商品 2018-2026 不存在**；**B) 动量存在，但"时序方向"形态失效（尤其空头腿）**。横截面动量用**同一时间点的相对强弱**构造多空组合，是检验 B 的直接设计：

**在 30 品种、2018-2026、L=120 排序收益下，截面 25/75 分位多空组合（净成本后）是否显著优于等权多头基准，且多头腿（赢家）与空头腿（输家）均有效。**

## 2. 假设（定死）

1. **相对强弱延续**：过去 L 日表现好的品种继续跑赢表现差的（赢家-输家价差延续）；
2. 该效应在中国商品期货 2018-2026 **净成本后**为正；
3. 价值来自**截面排序本身**（相对价值），非时序方向、非市场 beta。

## 3. 规则（定死，不可事后调参）

### 3.1 排序信号（冻结）
- 排序收益 `rL_i[t] = adj_close_i[t-1] / adj_close_i[t-1-L] − 1`（T-1 收盘决定，无前视）；
- 每日**截面分位**（当日可交易品种内排名；上市前/数据不足不参与）：
  - `rL ≥ 75 分位` → 多头；`rL ≤ 25 分位` → 空头；中间 → 0；
- **L = 120 交易日**（冻结）。

### 3.2 权重（冻结）
- 多头腿内**等权**（总名义 **+0.5**）；空头腿内等权（总名义 **−0.5**）——dollar-neutral，gross = 1；
- 每日再平衡；成本模型沿用 infra（0.02% + 0.05% 单边，冻结）。

### 3.3 灵敏度与分位诊断（仅报告，不选参）
- L ∈ {20, 60, 120, 250} 净夏普（高原判据）；
- 分位 ∈ {15/85, 25/75, 40/60} 净夏普（诊断分位边界敏感性）。

### 3.4 对照基准
- **基准 A（等权多头）**为主对照（G2）；基准 V（vol 长多）背景参照。

## 5. 诚实风险

1. **同一样本第三轮检验（多重检验风险显式承担）**：三方案同属"动量家族"，即使本轮通过，仅代表"该样本该形态有效"；§0 必须如实标注"未经未来样本外验证，且家族级统计显著性未校正"；
2. **30 品种分位粗粒度**：25% ≈ 7–8 只/腿，分位边界敏感（分位诊断覆盖）；
3. 与上两轮相同：做空约束未建模、主力连续小跳变未完全消除、成本为保守近似；
4. 若本轮否决，动量家族三连败 → 对"动量在中国商品 2018-2026 有效"的家族级证据倾向否定（如实记录）。
