**诚实解读（写死）**：
1. **V2 采纳理由**：协方差波动率目标达成"实现波动贴近目标 15%"（8.5%→15.3%，波动缺口收敛），夏普不变（0.468→0.472）——这是**风险可预测性**的提升（风控质量），收益随杠杆成比例上升（+3.96%→+7.21%），回撤相应放大（−16%→−28%）属杠杆选择的必然代价，非质量退化；
2. **V3 否决理由**：回撤减仓（12%/20%/6% 阶梯）在回撤中减仓 → 错过反弹、砍掉收益（夏普 0.47→0.27、Calmar 0.25→0.12），且因 T-1 反应滞后未压低最大回撤——**"回撤减仓一定有用"的直觉在此被数据证伪**；灵敏度（dd_mid 0.096/0.144）不改变价值为负的结论；
3. **C3 空头约束（诊断）**：sma20 空头 ≤30% 使夏普 −0.50→−0.48、回撤 −39%→−32%（小幅改善），但策略仍深度为负——空头约束是"止血"非"解药"，仅记录不采纳；
4. **纳入基准体系**：V2 成为新的默认风险框架（config `backtest.vol_estimator: "cov"`），未来策略对照统一用 V2 口径。

## 1. 背景与目标

1. **波动率目标补强（C1）**：现行 `vol_target_weights` 用"线性加权组合波动"近似，严重低估分散组合的真实波动（实现 8.4% vs 目标 15%）——换**滚动协方差**组合波动估计，使实现波动贴近目标（风险可预测性，风控质量指标，不直接追求 Sharpe）；
2. **回撤减仓 overlay（C2）**：组合回撤超阈值时阶梯降杠杆——测试"尾部风险控制"是否改善 Calmar/最大回撤（风险调整后收益的诚实检验）；
3. **空头约束诊断（C3）**：鉴于空头方向在全部含空方案中无正贡献，诊断"空头上限"作为组合层约束的影响（仅报告，不设门禁）。

## 2. 规则（定死，不可事后调参）

基础组合：**波动率目标长多**（基准 V 同款：等权×波动率倒数、目标年化波动 15%、max_pos_ratio 2.0、vol_min 0.05、每日再平衡、沿用 infra 成本）。在其上叠加：

### C1 · 协方差波动率目标（冻结）
- 组合波动估计：滚动 **60 日**样本协方差（ddof=0，min_periods=40）→ `port_vol[t] = sqrt(w_rel · Σ[t] · w_rel)`；
- 杠杆 = vol_target / port_vol，权重 = w_rel × 杠杆（截断 max_pos_ratio）；
- 协方差矩阵缺样本（预热期）→ 沿用线性近似兜底；
- **无前视**：Σ[t] 只用 returns[..t-1]（shift(1)）。

### C2 · 回撤减仓 overlay（冻结，阶梯规则）
- 组合净值相对运行峰值的回撤（T-1 计算，无前视）：`DD ≥ 12% → 总杠杆 ×0.5`；`DD ≥ 20% → ×0.25`；`DD < 6% → 恢复 ×1.0`；
- 覆盖在 C1 权重之上（乘性缩放）。

### C3 · 空头约束（诊断，仅报告）
- 空头名义 ≤ 总名义 30%（钳制）对"含空基准 B（sma20）"的影响——验证"限制空头"作为组合层约束的代价/收益。

**结论规则**：G1∧G2∧G3∧G4 → ✅ 组合层升级采纳为**新默认风控框架**（V3 入基准体系）；G1/G2 部分未过 → 🟡 部分采纳（注明）；均未过 → ❌ 如实记录"风控层不增价值，维持现状"。
**诚实边界**：C3 诊断结果单独报告，不进入门禁；若回撤减仓只是"降仓位换低回撤"（Calmar 不升），如实判定为无价值。

## 5. 诚实风险

1. **参数敏感**：回撤阈值（12%/20%/6%）、协方差窗口（60 日）为冻结参数——灵敏度（阈值 ±20%、窗口 40/80）仅诊断、不选参；
2. **同一 2018-2026 样本**：风险层指标仍在该样本评估（含金属牛市段），不外推；
3. **协方差估计成本**：杠杆随协方差变化 → 换手上升 → 成本拖累需如实计量（若吞噬收益，如实报告）；
4. **不宣称 alpha**：风控价值定义 = 实现波动贴近目标（可预测性）+ 回撤降低 + Calmar 不降；**不是更高收益**；
5. 若全部组合层升级被否决 → 结论"该样本期连风控层都无增量"，研究转向数据/外部验证。
