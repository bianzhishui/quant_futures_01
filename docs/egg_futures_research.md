# 鸡蛋期货交易案例调研

> 调研日期：2026-09-21 | 性质：公开资料整理（非实验），供研究参考
> 主题：鸡蛋期货（大商所 JD）作为"农产品看供给"的典型，历史大行情的供需逻辑，及与傅海棠框架（fu-haitang-supply-demand skill）的对应
> 说明：JD0 不在本项目品种池（大商所接口受限，无历史数据文件），本调研以公开报道与研报为准，未做量化回测。

---

## 1. 为什么鸡蛋是"农产品看供给"的典型

- **鲜蛋不可长期储存**：产蛋后数天即需出货，供给端几乎没有库存缓冲 → **价格对供给变化反应剧烈**（"供需矛盾看库存"在此失效，看的是存栏而非库存）；
- **供给 = 在产蛋鸡存栏**：由**补栏/淘汰周期**决定（蛋鸡 4 个月开产、12-18 个月淘汰），存栏变化传导到供应需数月——**存栏数据是鸡蛋的"成本/供应锚"**；
- **成本 = 饲料（玉米+豆粕）**：蛋价跌破饲料成本 → 养殖户亏损 → 淘汰鸡 → 存栏下降 → 供应收缩（傅海棠"亏损 → 供应收缩"链条在鸡蛋上周期最清晰）；
- **季节性**：中秋/端午/开学备货旺季、梅雨除霉淡季；价格在供给驱动上叠加明显季节性。

## 2. 历史大行情案例复盘

### 案例 A：2017 年"跌破成本 → 淘汰 → 暴涨"（傅海棠框架教科书）
| 阶段 | 事实（来源：证券日报/中国证券报 2017） |
|---|---|
| 高利润补栏 | 2015-16 养殖高利润 → 大量补栏 → 2016-11 在产蛋鸡存栏 12.71 亿只（同比 **+4.87%**） |
| 供给过剩 + 需求塌 | 2016-12 H7N9 禽流感爆发（16 省市、298 例感染/99 例死亡），需求降约 20%，环保关停食品厂 |
| 跌破成本 | 2017-02 现货 2.18 元/斤（两年新低），**跌破成本 2.7-2.8 元/斤**——全行业深度亏损（湖北浠水全养殖户亏损持续一月；每只蛋鸡亏 19.02 元、每斤净亏 1.25 元） |
| 跌至十年新低 | 2017-03-28 ~ 05-31 主力合约再跌超 20%，现货产地收购价 **1.8-1.9 元/斤（近十年新低）** |
| 供应收缩兑现 | 深度亏损 + 资金断裂 → **大量提前淘汰蛋鸡** → 5 月底存栏环比降 4.5%、同比降 4.2%（鸡龄变小） |
| 暴力反转 | **2017-06-01 鸡蛋 7 个合约齐涨停**，主力 1709 成交/持仓接近 2014 年高点；后续 7 月-中秋季节性上涨 |

**傅海棠对应**：跌破全行业成本（铁底）→ 供应端实质收缩（淘汰鸡、补栏停滞）→ 需求仍在（蛋白刚需）→ 暴力反弹。**"贱极则贵"在鸡蛋上的完整闭环**。

### 案例 B：2014 年"火箭蛋"（存栏低 + 中秋旺季）
- 2014 年蛋鸡存栏处于周期低位，叠加中秋备货旺季，鸡蛋期价大涨、成交持仓创新高（2017-06 文章回溯对比"2014 年大涨时主力合约"）。

### 案例 C：2019 年"非洲猪瘟替代"（需求驱动大涨）
- 2018 起非洲猪瘟导致生猪供给大幅收缩 → 猪肉蛋白缺口 → **鸡蛋/禽肉替代需求爆发**；
- 2019-06 起"中秋行情 + 猪瘟替代影响，蛋价走强概率大"（格林大华研报）；2019-07 市场"产业向左资金向右"的激烈博弈（一德期货）——鸡蛋期价在替代逻辑下大幅上行。

### 案例 D：2021-2022 年（存栏低位 + 饲料成本上行）
- 2020 疫情后补栏受挫，存栏持续低位；2021-2022 玉米豆粕饲料成本大幅上行 → 成本推动 + 供应偏紧，蛋价维持高位（成本锚在鸡蛋上直接可见）。

### 案例 E：2024-2025 年（存栏回升 → 过剩 → 下跌）
- 2024 年旺季（中秋）却现大跌、创**近十年新低**（证券时报）——2023-2024 高利润刺激补栏 → 存栏回升 → 供给过剩；
- 2025-05"供需过剩，卖近买远正当其时"（中国金融信息网）——近月弱、远月预期改善（市场预期远期去产能）。

## 3. 傅海棠框架解读（与本仓库筛选器的关联）

1. **鸡蛋是"供给驱动"的最纯粹标的**：成本（饲料）→ 盈亏 → 补栏/淘汰 → 存栏 → 供应 → 价格的传导链清晰，且鲜蛋不可储存使"库存缓冲"失效——**傅海棠"农产品看供给"的最佳实证品种**；
2. **2017 案例 = 贱极筛选器的理想样本**：价格 5 年低分位 + 深跌（2017-03~05）→ 若当时在池内，"跌破成本 + 供应收缩（淘汰）"的人工确认会直接命中——**这正是阶段一/二"机器筛、人确认"分工想要抓的形态**；
3. **数据可得性**：
   - JD 价格数据：akshare 可得，但大商所接口受限（本仓库未纳入）；
   - **存栏/淘汰鸡/补栏数据**（蛋鸡存栏、鸡龄结构）：芝华数据/卓创/博亚和讯等，**付费为主**——是鸡蛋的"成本/供应锚"，可类比我们缺失的"全行业成本"数据；
   - 饲料成本（玉米+豆粕）我们已有（C0/M0 主连可算）——**可做"蛋价 vs 饲料成本"盈亏代理**；
4. **启示**：若要纳入鸡蛋，最有价值的量化锚是 **蛋价/饲料成本比（盈亏）** + **存栏周期位置**（付费数据）；在当前"金属高位"环境下，鸡蛋这种"供给侧、可实证"的品种恰好符合傅海棠框架的适用边界（与贵金属/有色的金融属性形成对照）。

## 4. 诚实边界

- 本调研为**公开资料整理**，案例数字以引用的报道/研报为准，未做独立数据核验；
- 2014/2019/2021-22 案例为定性复盘（来源标题可查），具体涨幅未逐一核实；
- 鸡蛋作为鲜货，现货数据、存栏数据等核心基本面数据**免费可得性差**，量化落地需付费数据源或先以"蛋价/饲料成本比"做盈亏代理；
- 与傅海棠框架的对应是**解读性**的，非回测验证。
