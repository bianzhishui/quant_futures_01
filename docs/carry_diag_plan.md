| 判据 | 判定 | 数字 |
|---|---|---|
| C1 有色独立 | ❌ | 非有色(14)：carry 夏普 **+0.258** vs 同子集基准 A **+0.459**（**跑输**）；仅有色(6)：carry **+0.572** vs 基准 A **+0.387**（大幅跑赢）→ **正超额几乎全部来自 6 个有色品种** |
| C2 定义稳定 | ❌ | 全品种 slope_oi1/oi2 符号一致率中位数 **65.2%**（<70%）、面板 Pearson 相关 **0.323** → 斜率定义不稳定 |
| D3 辅助 | 排除简单解释 | 黑色 backwardation 占比最高（67.1%），有色仅 54.0%——**不是"有色更常 backwardation"** 导致有色 carry 强 |

**逐品种符号一致率**：CU 47.1 / AL 49.5 / ZN 50.2（有色核心品种接近随机）、CF 54.6、SN 59.2；最高 HC 71.5、FU 75.1。→ **有色上 carry 有效，但其斜率定义最不稳定**（≈随机），说明有色正超额更可能来自"持仓量排名/近月集中的系统性偏置"而非稳健的期限结构信号。

**对主结论的修正建议（写死）**：
1. **carry 🟡 主结论降级**：+0.52 vs +0.51 的超额**主要是 6 个有色品种的非稳健现象**（跨板块不成立 + 定义不稳定），不能视为"carry 期限结构溢价在中国商品成立"的证据；
2. **削弱跨来源印证**：此前 RESEARCH.md/AGENTS.md 表述的"多头/backwardation 方向有正溢价（双来源印证）"须修正——**动量家族的长多腿为正（三轮一致，独立成立）**仍保留；**carry 作为第二个来源的印证不成立**（正超额限于有色且定义不稳定）；
3. **方向结论**：在当前数据与定义下，carry 方向证据不足，**倾向放弃**；除非后续换数据（DCE 补全、逐合约展期、更稳的期限结构定义）重开。

## 1. 背景与目标

carry 🟡 结论（backwardation 多头 +0.60 正溢价）是否可靠，取决于两件事：
1. **正溢价是否仅来自有色板块**（G2c：有色贡献 51.2%，多为 backwardation）——若排除有色后溢价消失，则结论须修正为"有色板块的 backwardation 溢价"；
2. **斜率信号对远月定义是否稳定**（G2b：次主力 oi1 净夏普 +0.52，第 3 远月 oi2 净夏普 −0.21 反号）——若两定义的**符号一致率**很低，说明斜率信号本身不稳定（近月/远月选择噪声），carry 结论可靠性存疑。

**目标**：用三个定向诊断回答"carry 正溢价是否真实、是否稳健"，并为后续（继续深挖 / 转仅多头 / 放弃）提供依据。

## 2. 诊断规则（定死）

### D1 · 有色剥离（G2c）
- 在 carry 20 品种内，按 sector 分两组：
  - **D1a 非有色**（14 品种：黑色 2 / 贵金属 2 / 能化 6 / 农产品 4）；
  - **D1b 仅有色**（6 品种：CU AL ZN NI SN SS）；
- 每组分别跑：carry（oi1 符号，等权）+ 基准 A（同子集），2018-2026 同区间、同成本模型；
- 记录：净夏普、年化、多空腿分解。

### D2 · 远月定义符号一致性（G2b）
- 对每品种逐日比较 `slope_oi1` 与 `slope_oi2` 的**符号**（剔除 |slope|<1e-4 的模糊日）：
  - `sign_agree_pct` = 两定义同号天数 / 可比天数（品种 × 日）；
  - 面板级 slope_oi1 与 slope_oi2 的 Pearson 相关；
- 输出：全品种汇总 + 每品种明细。

### D3 · 有色 vs 非有色符号结构（辅助）
- 两组的 backwardation 占比（slope>0 比例）、斜率均值——判断"有色多 backwardation"是否成立（支撑/削弱 D1 解读）。

## 3. 判定标准（写死）

| # | 判据 | 结论 |
|---|---|---|
| C1 有色独立 | D1a（非有色）carry 净夏普 > 0 **且** > 同子集基准 A | → carry 正溢价**非有色专属**，跨板块成立 |
| | D1a 净夏普 ≤ 0 或 ≤ 基准 A | → 正溢价**主要来自有色**，主结论须修正为"有色 backwardation 溢价" |
| C2 定义稳定 | 全品种 sign_agree_pct ≥ 0.70（中位数） | → 斜率定义基本稳定，oi2 反号源于边际/权重效应 |
| | < 0.70 | → 斜率信号**不稳定**（近/远月选择噪声），carry 结论可靠性存疑 |

**综合结论规则**（写死）：
- C1 ✅ ∧ C2 ✅ → carry 正溢价**真实且跨板块**，可考虑深入（执行模型/仅多头）；
- C1 ✅ ∧ C2 ❌ → 溢价真实但**定义敏感**，须先解决远月定义再论；
- C1 ❌ ∧ C2 ✅ → **有色专属溢价**，修正主结论；
- C1 ❌ ∧ C2 ❌ → **carry 结论不可靠**，倾向放弃该方向。

## 4. 诚实风险

1. 诊断仍是**同一 2018-2026 样本**的描述性分解，不增加样本外证据；结论是"成色判断"而非"验证"；
2. 有色剥离后样本更小（14 / 6 品种），单板块区间数字噪声更大——以"符号 + 与同子集基准对比"为主判据，不以绝对值定论；
3. 本诊断**不改变** carry 已归档的 🟡 主结论，只输出修正建议；
4. 若结论为"有色专属"或"不可靠"，需在 §0 如实更新对"多头/backwardation 溢价"这一跨来源发现的表述。
