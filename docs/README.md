# docs — 项目文档目录

存放设计文档、研究方案、决策记录（与代码分离，scripts/ 只放可执行脚本）。
**历史实验的预注册方案已随实验单元归档**（索引见 `archive/INDEX.md`），
docs/ 只保留现行/权威文档。

## 约定

- **命名**：`{topic}_plan.md`（预注册方案）或 `{主题}_{类型}.md`（设计/决策记录）；
- 研究方案遵循**预注册原则**：实验实施前写死假设/规则/判定标准；
- 实施结果写回同一文档的 **§0 实施结果归档**（含失败）再提交 commit；
- 实验结束后 plan 随单元归档（`archive/experiments/`），docs/ 不留已完成探索的 plan。
