# 贱极×政策宽松 组合筛选器 · 使用说明

> 预注册方案：docs/screener_plan.md（2026-09-21 批准，✅ 正式采纳）

## 这是什么

把傅海棠框架中**可量化的两个已验证维度**组合成日常筛选工具：
- **贱极**：价格 5 年分位 ≤ 10% 且距 250 日高点回撤 ≥ 30%（历史净超额 6m +3.6% / 12m +8.4%）；
- **政策宽松**：M2 同比 > 36 个月中位数（宽松期贱极超额 +7.3% vs 收紧期 +2.0%）。

组合条件（冻结）：**贱极 ∧ 政策宽松**，历史净超额 6m **+7.3%** / 12m **+17.4%**（33 个事件，两窗口同号）。

## 运行流程（机器筛 → 人确认 → 决策）

```bash
# 1) 数据刷新（按需；数据已落盘可跳过）
.venv/bin/python scripts/fetch_data.py --start-date 2005-01-01   # 主连日线
.venv/bin/python scripts/fetch_macro.py                          # M2 月度（~1 分钟）
.venv/bin/python scripts/fetch_warehouse.py                      # SHFE 仓单（~11 分钟）
.venv/bin/python scripts/fetch_termstructure.py                  # 期限结构（~30 分钟，可选）

# 2) 跑筛选器
.venv/bin/python scripts/run_screener.py
```

**输出**：
- `output/screener_candidates.csv` —— 当前全品种维度表（价格分位/深跌/波动/期限结构/政策状态/仓单分位/组合候选标记）；
- `output/screener_stats.csv` —— 组合 vs 纯贱极 vs 收紧 的历史分组超额；
- `output/screener_gates.json` —— 门禁判定。

**人工二次确认（傅海棠框架的不可自动化部分，必做）**：
对 `combo_candidate=True` 的品种，确认三条（任一不满足 → 放弃）：
1. **成本**：是否跌破全行业成本、生产者深度亏损（行业数据/调研）；
2. **供给**：供应是否实质性收缩（种植面积/产能退出/库存低位——仓单只是代理，须看社会/隐性库存）；
3. **现货**：现货是否开始缺货、现货价是否率先启动。

## 纪律

- **只筛不决**：筛选器不产生买卖信号，只缩小人工确认范围；
- **等待是功能**：当前（2026-09）组合候选为 0——"静若处子"，不是 bug；
- 决策仍须遵守本仓库预注册纪律（若要从候选池发展成策略，另立方案）。
