**测量升级的核心发现（如实记录）**：

3. **该偏差不影响主结论**：C1 复验显示 TSMOM 在干净测量下仍为负（且因捕获正展期而亏损减半，−0.16 vs −0.30，方向不变）——"金属 beta、无跨板块信号"结论**稳健**；
4. **对未来策略的测量含义**：真实持有近月合约会吃到 backwardated 品种的正展期（sina 连续低估了这类多头策略的真实收益）——若未来做"吃展期"的仅多头设计，须用逐合约执行而非 sina 连续。

## 1. 背景与目标

1. **测量完整性**：既有结论基于 sina 主力连续（拼接有换月噪声、展期收益被剔除）——用**逐合约真实执行**重建干净测量，确认"金属 beta"结论在更干净数据下是否稳健；
2. **DCE 数据可行性**：如实判定大商所逐合约数据在免费源下是否可得；
3. 产出正确的**逐合约回测执行引擎**（未来任何策略的诚实执行层），以及"现货 vs 展期"收益分解。

## 2. 数据可行性结论（2026-09-21 实测，方案据此定稿）

| 数据 | 结论 |
|---|---|
| DCE 逐合约（akshare `get_futures_daily`/`get_dce_daily`） | ❌ 失效（JSONDecodeError，且 get_dce_daily 仅按日） |
| DCE 官网直爬（`exportDayQuotesChData.html`、历史数据页） | ❌ **HTTP 412 + JS 动态挑战（反爬 WAF）**，浏览器头亦被拒，静态历史页同样被锁——**免费源不可得** |
| SHFE/CZCE/INE 逐合约（已缓存 `data/_raw_term/`） | ✅ 2018-2026 齐备，20 品种 → **逐合约执行模型立即可建** |

→ **范围决定**：逐合约执行模型覆盖 SHFE/CZCE/INE **20 品种**；DCE 10 品种维持排除（范围局限如实记录，换付费源/等 akshare 修复后另立预注册补充）。注：动量主结论基于 30 品种 sina 主力连续，**不受本轮范围影响**（复验在 20 品种子集内进行，与 sina 版同子集对比）。

## 3. 规则（定死，不可事后调参）

### 3.1 逐合约执行模型（roll simulation，冻结）
- 每品种每日持有 **OI 最大合约**（与期限结构 F1 定义一致，冻结）；
- **换月**：T-1 收盘按 OI 规则确定 T 日应持合约；若与当前持有不同 → T 日换月，付**单边成本**（滑点 0.05% + 手续费 0.02%，沿用 infra 冻结值）；
- **收益**：持有合约的 close-to-close 真实收益（逐合约数据，无拼接跳变；换月日新合约有前日价格，收益真实）；
- 输出：逐品种 roll 模拟收益序列 + 净值。

### 3.2 重建干净"主力连续"（冻结）
- 用 3.1 的收益序列累积出"OI-主力连续"（数学上 = 持有 OI 最大合约并每日换仓到 OI 规则目标的路径，无拼接噪声）；
- 与 sina 主力连续对比：差异 = **展期收益 + 合约选择差异**（分解项）。

### 3.3 复验（冻结）
- **C1 TSMOM 复验**：等权 TSMOM（L=120，冻结参数）在重建主力连续上复跑，与 sina 版（同 20 品种子集）对比——**结论稳定性**（金属 beta 模式是否仍在、方向是否反转）；
- **C2 金属展期分解**：AU/AG/CU/AL 的收益分解为"现货收益（重建连续）"与"展期收益（sina−重建）"——判断金属牛市由现货还是展期驱动。

## 4. 判定标准（写死）

| # | 门禁 | 判定 |
|---|---|---|
| G1 | DCE 可行性 | 已实测：❌ 不可行（WAF 封锁）→ 如实记录，范围维持 20 |
| G2 | roll 模拟对拍 | 逐合约 roll 模拟净值 == 重建主力连续净值（同一 OI 规则下数学等价，误差 < 1e-6） |
| G3 | 复验结论稳定 | TSMOM 在重建 vs sina（同 20 子集）上：净夏普方向与金属 beta 模式**不反转** |
| G4 | 工程 | pytest 全过 + ruff 0 + import 过 + 两次运行一致 |

**结论规则**：G1 为记录项；G2 未过 → roll 模拟有 bug，须修复后才进入复验；G2 过 + G3 不反转 → ✅（结论在更干净测量下稳健）；G3 反转 → 🟡（原结论受测量影响，须重估）。

## 5. 诚实风险

1. **DCE 缺失**：逐合约层仅 20 品种；若未来换源补全，另立预注册重验；
2. **换月规则 ≠ 真实交易**：OI 排名换月忽略流动性/手续费结构差异，换月成本为保守统一假设；
3. **测量升级不产生新信号**：本轮不追求新 alpha，目的是确认既有"金属 beta"结论的稳健性；若 C2 显示金属收益主要来自现货（而非展期），说明"金属 beta"结论更不可能被展期测量偏差解释；
4. 仍是同一 2018-2026 样本，无新增样本外证据。
