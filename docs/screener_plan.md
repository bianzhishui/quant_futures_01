## 1. 背景与目标

阶段一/二分别确认：**价格贱极代理有边际**、**M2 宽松显著增强边际**。本轮：

1. **组合验证**：贱极 × 政策宽松 组合事件的历史超额，是否显著强于纯贱极（判定"组合筛选器是否值得正式使用"）；
2. **当前市场扫描**：输出当前每个品种的完整维度表（价格分位/深跌/波动/期限结构/政策状态/库存标注）+ "贱极+宽松"候选池，供人工确认（成本/供给/现货缺货）；
3. **使用流程**：固化"定期扫描 → 人工二次确认"的工具化流程。

## 2. 规则（定死，不可事后调参）

### 2.1 组合条件（冻结）
- **贱极**：D1 价格 5 年分位 ≤ 0.10 且 D2 距 250 日高点回撤 ≥ 30%（阶段一同一定义）；
- **政策宽松**：事件日所属月 M2 同比 > 过去 36 个月滚动中位数（阶段二同一定义）；
- **组合 = 贱极 ∧ 宽松**（冻结）。

### 2.2 历史组合验证（冻结，同口径）
- 事件集 = 阶段一同一事件（去重 ≥60 日、持有 6/12 个月、扣往返成本、等权基准）；
- 分组：**组合（贱极∧宽松）** vs **纯贱极（全部）** vs **贱极∧收紧**；
- 输出各组 6m/12m 净超额、事件数。

### 2.3 当前市场扫描（冻结）
- 截至最新交易日：每品种 D1–D4 + 政策状态 + 库存标注（SHFE 品种仓单分位）+ **组合候选标记**；
- 候选池 = 当前满足组合条件的品种（若存在）；附各品种完整维度供人工确认。

### 2.4 使用流程（写死）
1. `run_screener.py`（数据管道先行：fetch_data / fetch_macro / fetch_warehouse / fetch_termstructure）；
2. 输出候选池 → **人工二次确认**：成本是否跌破（行业数据）、供给是否收缩（调研）、现货是否缺货（现货数据）——傅海棠框架"机器筛、人确认"分工；
3. 确认后才进入决策；筛选器**只筛不决**。

## 5. 诚实风险

1. **组合样本有限**：宽松期贱极事件仅 33 个（阶段二）——组合事件数可能 20-30，统计力中等；
2. **同一 2010-2026 样本**：组合验证仍是样本内特征组合，非独立样本外；
3. **当前市场贱极稀缺**：阶段一快照显示当前无贱极候选 → 筛选器当前输出可能为空/极少（等待信号本身是功能，不是 bug）；
4. **筛选器只筛不决**：不产生买卖信号，须人工用成本/供给/现货确认（傅海棠方法不可全自动化部分）。
