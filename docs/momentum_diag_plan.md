2. **终极结论**：5 个方案的全部信号发现（动量长多腿、carry 正溢价）**最终都归结为 2018-2026 有色+贵金属两大牛市板块的 beta**（沪金 ≈4.7 倍、沪银 ≈10.5 倍、有色大涨）——本样本期本身被金属超级牛市主导，任何偏向金属的多头信号都会"看起来有效"，但这是**样本运气/后视，非可交易 edge**；
3. **对研究的含义**：①（仅多头动量）**不获证据支持**；在该样本上继续挖信号的意义已很低——建议**转向组合/风控层**（③：波动率目标补强、回撤控制、多空不对称仓位设计），或接受"该样本期简单信号无效"的结论；
4. 诊断不改变三方案已归档的 ❌ 主结论，仅将附随的"长多腿为正"发现一并修正为板块 beta。

## 1. 背景与目标

回答一个问题：**动量家族长多腿的正贡献，是否跨板块成立？**

- 若长多腿正贡献**主要由贵金属+有色驱动**（剔除后消失）→ "多头方向有正贡献"只是 2018-2026 两大牛市板块的 beta，**非可交易 edge**，研究结论须证伪修正，转向组合/风控层；
- 若剔除后**仍为正** → 长多腿发现保留（强度可能下降），可谨慎考虑仅多头设计（承担多重检验）。

## 2. 诊断规则（定死）

对象：动量家族 3 个设计（均用已冻结参数）：
- TSMOM 等权（L=120）；vol-TSMOM（L=120）；XSMOM（L=120, q=0.25）。

### D1 · 长多腿板块分解
- 对每个设计：`long_leg_sector = Σ_{i∈sector} (w_i.clip(lower=0) × r_i)` 的累计值；
- 输出每板块对**长多腿**的累计贡献（不是净贡献——现有 sector CSV 是净贡献，无法隔离多头腿）。

### D2 · 剔除贵金属+有色后长多腿复算
- 剔除 {AU, AG, CU, AL, ZN, NI, SN, SS}（贵金属 2 + 有色 6 = 8 品种）后，重算各设计的长多腿累计贡献；
- 对照：全品种长多腿累计贡献。

### D3 · 时段结构
- 长多腿累计贡献按 2018-2021 / 2022-2026 分段（观察是否集中于某段，呼应 carry 的"2022 后边际消失"）。

### D4 · 板块 beta 对照（辅助）
- 基准 A（等权多头）的板块累计贡献——验证"贵金属+有色就是同期最大上涨板块"这一前提。

## 3. 判定标准（写死）

| # | 判据 | 结论 |
|---|---|---|
| C1 板块集中 | 贵金属+有色对长多腿累计贡献占比（三设计均值）≥ 60% | → 长多腿正贡献高度集中于两牛市板块 |
| C2 剔除后存活 | 剔除贵金属+有色后，长多腿累计贡献 > 0 的设计数 | ≥2 → 跨板块仍有正贡献；≤1 → 主要靠板块 beta |

**综合结论规则**（写死）：
- C1 ✅ 且 C2 ≤ 1 → **"动量长多腿为正"降级为"贵金属+有色板块 beta"**（2018-2026 牛市后视），全部信号发现证伪 → 建议转向组合/风控层（或仅在这些板块押多 = 赌板块延续，不判为稳健策略）；
- C1 ❌ 或 C2 ≥ 2 → 长多腿**跨板块仍有正贡献**，结论保留（标注强度），① 可谨慎推进（承担多重检验）。

## 4. 诚实风险

1. 仍是**同一 2018-2026 样本**的描述性分解，不增加样本外证据；
2. 剔除 8 品种后样本变小（22 品种），长多腿数字噪声增大——以"符号 + 多设计一致性"为主判据；
3. 诊断**不改变**三方案已归档的 ❌ 主结论，只输出对"长多腿为正"这一附随发现的修正；
4. 若结论为"板块 beta"，须在 §0 与 RESEARCH.md/AGENTS.md 如实更新"多头方向正贡献"的表述（与 carry 诊断同理）。
